# P0.6 MCP integrity baseline reseed on deploy
Date: 2026-11-10; incident: rsi-ca0351661b7f40e08d42ab50.

## Failure and owner decision
Accepted MCP changes leave the root-owned hash baseline stale, failing the hourly
integrity unit and deploy QA check 0.1.2. Owner authorized automatic reseeding at
the end of a successful verified deployment, with an old-to-new audit diff.

## Frozen design
- Updater appends one JSON audit record before installing each nonempty baseline.
- Record UTC time, invoking actor, supplied revision, changed/added/removed paths
  and counts; first seed records all paths as added. Print counts and <=10 paths.
- Audit defaults beside the baseline; MCP_INTEGRITY_AUDIT_LOG overrides it.
- Deploy step 8b follows verification, runs only with rc==0, precedes QA step 9.
- Read source/baseline paths from the live integrity unit Environment; absent
  unit/environment warns and skips. Never evaluate environment text as shell.
- Reseed with sudo env and HEAD provenance, then start the integrity check;
  either failure sets rc=1. Dry run only describes the action.
- Scope: PRD, updater, deploy command, regression test, CI manifest and delegate
  PULSE/RESUME. No Nix changes, sudo execution or live baseline/service changes.

## Threat model
Reseed happens only after aq-deploy-current verified configuration revision equals
HEAD, is not -dirty, on main: hashed content is the reviewed, merged, deployed
commit under the deploy source guard. Integrity detects drift between deploys.
Residual risk: tampering before a deploy is caught only if the operator reads the
audit diff; working-tree mutation during deployment remains an operator trust risk.
Audit append failure must prevent baseline replacement; empty input must preserve
both the prior baseline and audit. No new dependencies beyond Python stdlib.

## Acceptance
bash -n both scripts; temporary-fixture regression proves first seed, exact
changed/added/removed diff and empty refusal; static deploy guard/order checks;
aq-deploy-current --help and CI manifest validation exit zero; py_compile test.
Live deployment and independent acceptance belong to the orchestrator/operator.

## Rollback
Revert this slice to remove automatic reseeding; preserve audit records and restore
an operator-reviewed baseline if needed. Never silently bless or erase drift.
