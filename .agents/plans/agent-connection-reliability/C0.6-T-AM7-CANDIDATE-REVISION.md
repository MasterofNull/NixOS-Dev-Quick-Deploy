## 3. Required corrections and regression closure

### 3.1 Frontend coordinator availability and worst-severity composition

Coordinator data is available only when the response is object-shaped and its
explicit `available` member is not `false`. Missing, `null`, malformed, and the
exact backend fallback object with `available: false` are unavailable.
Local-direct retrieval and rendering remain independent. The combined Agent Ops
badge must select the worst frozen severity across coordinator and local-direct
states and must never improve either source.

Required regression vectors:

- the exact backend `available: false` fallback crossed with every local-direct
  state;
- available, missing, `null`, malformed, and unavailable coordinator responses;
- local-direct rendering when coordinator retrieval fails;
- deterministic worst-severity selection for every crossed pair.

### 3.2 Effective cache age on every return path

Every cached return path must use one pure effective-age projection followed by
final schema and semantic validation. This includes the ordinary in-TTL fast
path, refresh success, refresh-failure fallback, shared-waiter return, and
cancellation fallback. No path may return stored payload bytes unchanged.

The cache must retain accepted payload bytes, accepted `source_age_s`, and an
injected monotonic acceptance time. At return:

`effective_source_age_s = accepted_source_age_s + max(0, now_monotonic - accepted_monotonic)`

Projection operates on a copy, never mutates stored accepted payload, and may
only preserve or worsen health:

- age `<= 10s`: preserve the accepted classification;
- age `> 10s` and `<= 60s`: at least stale/degraded with `source_stale`;
- age `> 60s`: typed unavailable with assessed values erased to `null`.

Required regression vectors directly exercise both normal fast-path and
failure-fallback returns at exactly 10 seconds, immediately above 10, exactly
60, and immediately above 60 using a deterministic injected clock. They must
also prove no pre-existing worse reason, coverage, or classification improves.

### 3.3 Exact closed outer `aq.delegation-task-record.v1`

Before interpreting registry evidence, the adapter must validate every supplied
row against the exact closed outer `new_record` branch of
`aq.delegation-task-record.v1`. Only these top-level keys are permitted:

`record_version`, `task_id`, `lane`, `role`, `access`, `task_class`,
`artifact_expectation`, `created_epoch`, `record_revision`,
`admission_producer`, and `status`.

The exact types, constants, enums, integer bounds, task-id pattern, and
boolean-as-integer rejection frozen in AM6 remain mandatory. Transition and
process-attachment operations are not registry source records and must reject.
Any extra key, nested payload, malformed required value, or mixed valid/invalid
source rejects the entire source as blocked/source-invalid. An exact valid v1
row carries no local-direct telemetry and therefore maps only to typed
not-assessed/source-not-instrumented evidence.

Required regression vectors cover:

- every permitted field with a malformed type or value;
- arbitrary unknown keys and the named `local_direct`,
  `local_direct_attempted`, `trusted`, `producer`, and `provenance` attempts;
- nested payload attempts and operation-object attempts;
- mixed valid/invalid rows with no selective salvage;
- one exact valid v1 row proving it is not promoted to assessed or trusted.

### 3.4 One absolute child lifecycle budget

The backend probe gets one injected absolute monotonic deadline of at most two
seconds. Spawn, stdout/stderr reads, combined output cap, terminate, kill, and
confirmed reap must all fit inside that one budget. Every await or blocking
boundary consumes only remaining time; cleanup cannot open another window.

Cancellation and shared waiters must not orphan or duplicate a child. Neither a
normal response nor cached fallback may return until the owned child is
confirmed terminal and reaped. Failure to confirm reap by the deadline must
propagate a fixed cleanup-integrity failure.

Required regression vectors put the deadline immediately before, at, and after
spawn, read, output-cap, terminate, kill, and reap boundaries. They also cover
caller cancellation, shared waiters, non-returning
terminate/kill/wait doubles, total elapsed time, terminal state, one refresh
owner, and explicit unconfirmed-reap propagation.

### 3.5 Terminal timestamp ordering

Any terminal record with `terminal_at_ms < phase_entered_at_ms` rejects the
entire source as blocked/source-invalid. The implementation must either enforce
this in the reachable validator with a direct negative regression vector or
remove the unreachable helper and directly test the surviving validation path.
The existing upper future-skew bound remains unchanged.
