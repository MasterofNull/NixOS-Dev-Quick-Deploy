VERDICT: REVISE

All three features target real live paths (`route_handler.py`, `mcp-bridge-hybrid.py`, `agent_executor.py`), and the overall scope is lean. However, two P0 defects in A3 and four P1 gaps across A1–A3 must be resolved in `DESIGN.md` before implementation.

FINDINGS:

1. **[P0] A3 threshold math collides/inverts for `limit <= 10` and is undefined for `limit < 3`**
   - Evidence: [DESIGN.md](file:///home/hyperd/Documents/NixOS-Dev-Quick-Deploy/.agents/delegation/worktrees/feat-athena-patterns-prd/.agents/plans/athena-patterns-20261127/DESIGN.md#L120-L122), [DESIGN.md](file:///home/hyperd/Documents/NixOS-Dev-Quick-Deploy/.agents/delegation/worktrees/feat-athena-patterns-prd/.agents/plans/athena-patterns-20261127/DESIGN.md#L130-L134).
   - With `soft=0.80`, `hard=0.95`, `reserve=2`: `limit=10` gives `soft_at=8 == hard_at=8`; `limit=3..9` inverts (`soft_at > hard_at`); at `limit=3`, `hard_at=1` makes `1 <= soft_at < hard_at` unsatisfiable. Similarly, `wall_budget_s <= 300` makes `limit - reserve_s <= 0`.
   - Design change: Pin exact clamping: for integer calls with `limit >= 3`, `hard_at = max(2, min(ceil(hard * limit), limit - reserve, limit - 1))` and `soft_at = max(1, min(ceil(soft * limit), hard_at - 1))`; for `limit == 2`, emit `hard` only at `1` (`soft_at = None`); for `limit <= 1`, disable. For wall seconds, cap `reserve_s = min(reserve_s, limit_s * (1 - hard))` and clamp `0 < soft_at < hard_at < limit_s` (disable if `limit_s <= 0`).
