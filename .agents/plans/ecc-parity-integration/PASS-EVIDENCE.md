## Machine classification rules

`SOURCE-READ-LEDGER.json` records every path/blob/type/size. `source_family` is
the first path component. `reader` and `evidence_pointer` identify the attributable
pass above. Content classification is deterministic and conservative:

- Git symlink/submodule/tree modes are explicit.
- Common media/archive/font/database extensions are `binary-by-extension`.
- package/dependency lock files are `generated-lock`.
- all remaining blobs are `text-or-unknown`; this does not assert UTF-8 or
  hand-authorship.

Metadata acquisition and classification are not semantic review. Cataloged rows
remain unread unless a pass explicitly raised their status.
