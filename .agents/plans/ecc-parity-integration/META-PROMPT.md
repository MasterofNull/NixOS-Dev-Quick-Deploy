## Objective

Implement missing **outcomes**, not matching file counts. Preserve AQ-OS's
declarative OS/runtime, memory, coordinator, review, security, installer and
dashboard authorities. Prefer a native extension of an existing SSOT over copied
ECC code. A feature is complete only with working implementation, tests, live or
fixture integration evidence as appropriate, QA and dashboard visibility,
documentation, atomic commit evidence and independent non-author acceptance.

## Coordinator algorithm

1. Select only the next dependency-ready bounded slice from the plan.
2. Resolve file/section claims before dispatch. All lanes share one directory;
   do not switch shared HEAD, stage unrelated files or assume worktrees.
3. Give every lane the same acceptance contract and exact owned files. Choose
   the cheapest eligible implementer; reserve an independent capable lane for
   final review. Local inference must receive genuinely eligible bounded work,
   not ceremonial prompts.
4. Require source evidence for any ECC-derived behavior and local evidence for
   any parity claim. Unknown remains unknown. Documentation is not enforcement.
5. Implement the smallest end-to-end outcome. Do not open another planning or
   review cycle for nonblocking disagreement: record it and route it to the next
   slice. Only safety, authority, data-loss, secret or acceptance-criterion
   failures block the current slice, and their fix must remain bounded.
6. Run focused tests, live/fixture integration, Tier-0 and security checks.
   Instrument the feature before optimization; add QA and dashboard coverage in
   the same slice or immediately consecutive commit on the same branch.
7. Obtain one final hash-bound independent verdict. Commit atomically with
   truthful authorship/review/validation/activation/exclusion evidence.
8. Update the gap ledger, implementation plan, resume/pulse/handoff and issue
   backlog. Surface owner decisions immediately; never silently park work.
9. Proceed to the next ready slice. Queue unavailable lanes for later advisory
   catch-up without crediting them or blocking accepted implementation.

## Prohibited shortcuts

- Bulk-copying 68 agents, 292 skills or 94 commands.
- Treating Antigravity's report, filenames, inventory counts or hash chains as
  semantic/runtime proof.
- Creating competing memory, orchestration, installer, policy or review SSOTs.
- Broad user-home writes, implicit Git stash/clear, global hooks or auto-update.
- Enabling network/write/secret/account/deployment authority from a prompt.
- Claiming GitHub enforcement without verifying repository-side settings.
- Endless revise/re-review loops after acceptance criteria are satisfied.
