The docs fetch used a summarizing model; items marked "not described" mean the page fetched did not cover it, not that OpenClaw lacks it.

Conclusion: nothing in OpenClaw closes a control-plane overlap rev4 lists (it is an assistant gateway, not a delegation/trust/landing system), and it fails C2. Keep as reference for the single-scheduler and per-agent skill-allowlist ideas.
